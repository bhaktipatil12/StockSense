# StockSense

StockSense is a modern inventory and warehouse operations platform designed to help teams track products, manage stock movements, monitor warehouse performance, and streamline operational workflows.

Built as a monorepo, the project combines a FastAPI backend with a Next.js frontend to provide a complete solution for inventory management, operations tracking, and analytics.

---

## Overview

StockSense supports:

- Product catalog management
- Multi-warehouse and location tracking
- Stock movements and operational workflows
- Receipts, deliveries, transfers, and adjustments
- Dashboard reporting and inventory insights
- User authentication and secure API access

This project is ideal for teams that need a clean and extensible inventory system with a practical backend and a modern dashboard interface.
